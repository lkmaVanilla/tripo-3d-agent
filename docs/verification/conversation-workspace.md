## 当前可用能力与边界

- 首页输入进入持续聊天工作台。同一匿名访客可有多个会话，一个会话围绕一个资产主题顺序执行多个独立 Run。
- 每个 Run 有独立预算、暂停/恢复、操作、核验和结局。澄清继续原 Run；运行、排队或停止退出期间仅保留后续草稿。
- 明确引用本会话的一个历史版本进行减面。预览和引用分开，跨会话引用、任意路径、URL、token、TaskID 导入均不开放。
- 所有实际产物追加版本；技术未通过的候选也保留。减面记录实际几何父版本，文本再生成仅记录上下文引用，旧文件与报告不改写。
- 历史输入上传前独立核对 GLB、摘要和大小。上传尝试跨重启最多三次；已知 TaskID 续查，未知提交不重发，停止不保证远端取消且不提供停止后恢复或取回。
- 纯说明与无需加工使用零生产回答；新交付必须来自本 Run 的实测合格产物。公开事实与 Agent 建议分别标明来源。
- 最后一个 Run 结束后整段会话保留七天；到期前正式接受新目标保护全部历史数据，浏览和下载不续期。

生产能力仍为文本生成、静态模型减面和技术解释。图片输入、外部模型导入、骨骼绑定、动画、跨会话资产库及多实例调度尚未接入。所有资产质量验收只有技术检查，不含视觉判断。旧 `/api/sessions` 创建固定 v2，新聊天固定 v3，空版本旧记录继续使用 v1。
