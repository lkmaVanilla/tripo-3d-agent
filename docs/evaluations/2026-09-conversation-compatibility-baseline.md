# v2 兼容基线与首批连续创作评测

本批完成 84 次真实 DeepSeek 运行和 84 次逐例语义审核，但未通过验收门槛。20 个固定场景误用了兼容入口 v2，因此这 60 次作为额外兼容模型基线保留；它们不能替代当前发布入口 v3 的 20×3 验收。其余 8 类×3 使用当时的 v3 指引。后续完整 v3 批次另存，绝不覆盖本批。

证据目录：[20260913T143651Z-1314001573](conversation-evidence/20260913T143651Z-1314001573/manifest.json)。运行共 459.840 秒、334 次模型调用、70 次固定 Provider 提交，真实 Tripo 调用为零。每次提交产生的检查数据来自合成 GLB。历史版本及预算耗尽是清单中预声明的夹具，不计为当前目标的真实模型生产能力。

## 结果

每个目标的每个维度计一个适用综合项，所有原始提议共同决定该项；不因某次调用工具更多而扩大分母。自动数值检查和逐句语义审核结合评分。三个维度分别要求至少 90%，关键错误必须为零。

| 范围 | 意图与澄清 | 策略选择 | 结果解释 | 语义关键错误 |
|---|---:|---:|---:|---:|
| v2 固定 20×3 | 59/60，98.33% | 59/60，98.33% | 53/57，92.98% | 2 |
| v3 连续 8×3 | 22/24，91.67% | 22/24，91.67% | 21/24，87.50% | 0 |
| 全部，仅供整体观察 | 81/84，96.43% | 81/84，96.43% | 74/81，91.36% | 2 |

三次未知提交由 Runtime 立即终止，Agent 没有收到反馈或形成最终说明的机会，结果解释维度不适用；程序生成的 Final 不算 Agent 解释成绩。空响应导致应有解释缺失的案例仍计失败。

v2 存在两条未经诊断的确定性失败原因判断，未满足零关键错误；v3 结果解释低于 90%。整体比例不能抵消单独范围的失败。

原始自动检查为 80/84 通过。`missing_reference/3` 因测试要求问满三轮而被误判；现行规格只规定最多三轮，用户明确仍不选择后，可以零生产说明结束。保留原始失败记录并在 [semantic-review.json](conversation-evidence/20260913T143651Z-1314001573/semantic-review.json) 单独记录规格对齐处理，对齐后的自动通过为 81/84；没有重跑该例或修改原始清单。完整逐例计数见 [summary.json](conversation-evidence/20260913T143651Z-1314001573/summary.json)。

## 失败与边界

- `baseline-v2/three_round_defaults/1`：两轮澄清后，`set_intent` 参数被截断为非法 JSON，最终未生产、未形成 Agent 解释。原版本将它显示为恢复失败。
- `conversation-v3/missing_reference/1`：先默认唯一旧版本并提出减面意图，被 Runtime 正确拦截；随后两轮澄清后模型返回空正文、空工具。Runtime 拦截不抵消 Agent 先前的越界选择。
- `conversation-v3/missing_reference/2`：加载加工 Skill 后模型返回空正文、空工具，未澄清也未形成答案。
- `conversation-v3/ambiguous_unknown_retry/3`：正确拒绝重发，但建议从选择器选中远端未知任务可能生成的版本。当前没有取回或导入，该版本并未进入本会话，因此建议不可执行。
- `baseline-v2/missing_output/2、3`：在成功响应缺少文件地址时，断言问题与提示词、面数、贴图参数无关，或不能通过调整参数解决。固定反馈没有排除这些原因的诊断证据。本审核将未经验证的确定性原因排除计入伪造验证结论，共两条关键错误；停止或有限重试本身是合法决策。
- `baseline-v2/always_over/2`：数字与超限判断正确，但原始收尾遗漏了 profile 要求的“未进行视觉检查”边界，记为解释遗漏，未计关键错误。

前三个空/截断响应样本的公开导出没有保留 `ResponseMeta`，临时库已在对应子测试完成后清理。无法从现有证据断言是 4096 token 上限或 thinking 耗尽导致。后续只读捕获的 25 条响应元数据不包含上述样本，见 [observed-response-metadata.json](conversation-evidence/20260913T143651Z-1314001573/observed-response-metadata.json)。没有将推测写成诊断结论。

本批没有真实供应商费用证据，334 次模型调用也不是 token 费用统计。公开提议和工具参数全部逐例审核，未将 Eino 思考正文导出或展示。
