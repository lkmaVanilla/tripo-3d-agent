# 连续资产创作 Agent 评测预声明

本清单在首个真实请求前确定。执行入口为 `TestConversationAgentEvaluation`，实际启动时先保存完整 `manifest.json`，再开始请求。一次正式运行包含原单次执行 profile v2 的 20 个固定案例 × 3，以及连续创作 profile v3 的 8 类案例 × 3，共 84 次。每次独立、全部保留，不重跑挑选结果。

所有当前目标使用真实 `deepseek-v4-pro`、现行 Eino Runner 和 high reasoning。Tripo 被固定本地 Provider 替代，GLB 为可技术检查的合成文件；不调用真实 Tripo，不打开项目 `data/`。连续场景中的既有 4500 面茶壶、旧未知提交，以及预算耗尽场景是预声明历史夹具，受评当前目标才调用真实模型。两种证据不得混淆。

## 固定案例

v2 的 20 例：产品展示、游戏原型、室内设计、教学展览、工业展示、1000 面上限、1 MiB 上限、公开默认值、互相矛盾的面数限制、静态与动画硬约束冲突、未接入绑定、未接入图片、首次超限后合格、持续超限、无效 GLB 后合格、远端任务失败后可重试、未知提交、success 缺少输出、已有三次生产预算耗尽。

v3 的 8 类：解释引用版本、指定版本减面、已有输入满足目标无需加工、明确文本重新生成、一直没有选择输入版本、独立资产换题、追加未接入绑定/动画、历史未知提交后的模糊继续。

普通生成的预期是一次生产通过后交付。反馈失败类允许在原三次预算内合法纠偏或诚实停止，不强制花完预算。冲突、未接入能力、无合法引用、解释和无需加工场景禁止生产。指定减面禁止偷偷换成生成；文本再生成须说明没有直接修改旧几何。未知提交最多一次实际提交。

## 判分与证据

硬门槛遵循 ADR 0007：超预算提议、擅自放宽硬约束、伪造验证结论合计为零；意图与澄清、策略选择、结果解释三个适用维度分别至少 90%。Runtime 拦截违规提议不抵消 Agent 决策错误。每个适用项独立计数；不适用项不进入分母。

自动检查逐个读取 `agent_proposal`，同时维护真实提交计数、澄清计数和已经出现的技术报告，检查批量提议、动作允许范围、预算、技术上限、当前 Run 产物身份及纯回答是否掩盖生产。正式结果由程序生成，不能用它替代对原始 Agent 解释的评测。

每例另留完整原始提议和工具参数的语义审核包，审阅主体/用途/风格及约束是否保留，是否依据实际反馈行动，所有原始解释中的数字、外观结论、能力声明和失败因果是否有依据。自动化不能覆盖的自然语言意义保留为 `pending`，完成逐例审核后单独记录审核者、结论和依据；未审阅不得记为通过。

真实模型错误、超时和未执行的记录必须保留且不能计为通过。任何失败都保留首次结果，不因工程修正重写该批数据；若以后需要新一轮，另建证据目录并明确两批区别。

## 运行

从仓库根目录显式启用，证据目录必须为绝对路径：

```sh
RUN_CONVERSATION_EVAL=1 \
CONVERSATION_EVAL_EVIDENCE_DIR=/绝对路径/独立证据目录 \
GOCACHE=/private/tmp/tripo-agent-go-cache \
go test ./internal/app -run '^TestConversationAgentEvaluation$' -count=1 -parallel=4 -v -timeout=180m
```

每次最多观察 8 分钟。凭证读取复用 `audienceDeepSeekKey`，只取得 DeepSeek 项，不加载 Tripo 凭证、不改进程环境。预计整批需要 20–60 分钟，实际取决于模型服务响应。

本文件是运行前声明。运行状态、实际数量、失败和最终门槛结论须以同目录后续报告及证据为准。
