## 删除的评分与案例

- 不评生成模型是否符合指定类别或外观、配色、材质、产物实际风格和部件完整性。
- 不评对历史模型具体形状、部件或外观的归因，也不评新旧模型视觉相似度。
- 不评解释是否包含“未做视觉检查”“外观符合性未知”等声明；遗漏这些声明不构成失败。
- 删除活动变更 `verified-results` 中“原始回答包含无依据外观断言”专用场景。
- 从混合测试中删除视觉断言，移除默认关键错误定向复测中的视觉 `product/1` 项；完整基线 `product` 仍保留非视觉覆盖。

上述排除适用于全部原始提议的正文、假设、计划、工具说明、生成提示词和最终说明，不只作用于最后一条回复。不能换成“真实性”“解释可信度”或“遗漏声明”的名称继续对同一视觉内容扣分。用户输入中的资产描述仍可作为创作输入；不据固定几何测试文件判断外观要求是否实现。原文中的风格与用途是否被正确保留、Agent 默认是否被错说成用户明确要求，仍属于非视觉的文本来源与意图检查；移除的是产物实际外观判断，不是输入事实核对。

## 保留的评测范围

意图与澄清检查用户目标、受众、明确技术约束、默认授权、最多三轮澄清和退出规则；策略检查输入版本授权、操作适用性、反馈驱动的纠偏、终态与实际执行一致；约束检查预算和硬约束；解释只检查技术报告、执行与提交状态、已执行能力、剩余额度以及技术因果依据。生成参数不等于实测值，技术失败不自动证明某个原因，Runtime 拦截不抵消 Agent 的非视觉违规提议。
