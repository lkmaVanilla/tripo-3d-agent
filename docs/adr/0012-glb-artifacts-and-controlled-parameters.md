# 首版交付静态 GLB，并限制 Agent 可调整的参数

首版需要让文本需求、Tripo 生产、技术检查和最小查看器形成一条可执行链路。接受文本输入，生成一个静态道具，以自包含的 GLB 单文件交付；允许文件内部包含多个网格，按所有网格的总三角面数验收。

Agent 仅可调整生成描述、目标面数和贴图质量，并遵守用户硬约束及所选模型的参数限制。Tripo 模型版本和其他参数由程序固定：关闭四边面、显式分件，不请求网格压缩。固定配置的具体版本和值在实现时明确记录。

生成目标与验收上限分别保存。例如，可以将目标面数从 5,000 降至 3,000，但不能将用户指定的 5,000 个三角面上限提高至 8,000；实际产物仍须检查。进入生产执行后固定本次验收上限，后续全局配置变化不影响已有请求。

用户未指定对应技术上限时，首版默认最多 5,000 个三角面和 10 MiB 文件体积，并在生成前公开展示；默认值只补全缺失字段，见 [ADR 0003](0003-technical-validation-only.md)。

这一选择控制了工具参数空间、检查器和查看器的支持成本，同时保留生成描述、几何规模和贴图质量上的策略选择。首版不加入独立格式转换或压缩网格解码能力。遇到压缩网格、外部资源依赖或不支持的格式时，明确报告不支持或无法验证，不能跳过检查后宣布合格。

Tripo 生成接口开启四边面会强制输出 FBX，且提供可选的网格压缩参数，见 [官方生成文档](https://developers.tripo3d.ai/en/docs/generation-text-to-model/standard)。减面接口的 v2.0 模式明确输出 GLB，见 [官方减面文档](https://developers.tripo3d.ai/en/docs/mesh-decimate)。这些接口信息不构成实际产物自包含、静态、无压缩或符合面数上限的保证，应用必须检查下载文件。
