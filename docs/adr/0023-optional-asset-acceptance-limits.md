# 技术验收上限可选，生产参数与系统保护独立

新聊天目标不再自动补 5,000 个三角面和 10 MiB。两项验收上限分别来自用户明确要求或引用版本的适用约束，无来源则保持未设置；用户可以在后续新目标明确修改或取消。生产目标面数是制作参数，不是用户验收标准，下载和解析资源保护继续独立执行。技术检查始终采集可核验数据，只对存在的上限做比较，未设置标为不适用。

本决定局部替代 ADR 0003、0012 的默认补全条款，保留其静态 GLB 支持范围和技术验证边界。无绝对上限的进一步减面须以真实面数变化证明目标完成；技术通过不自动证明加工目标完成。

新目标使用 v4 协议，已有 v1/v2/v3 执行及旧单请求创建入口保留原语义。选择显式版本与三态约束变更，避免用零值混淆继承/取消，或原地修改提示和报告而破坏 checkpoint 与历史事实。旧记录无法证明约束来源时，标为继承的历史约束，不猜测其是否由用户提出。
