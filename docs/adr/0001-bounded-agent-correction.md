# 采用单 Agent 执行有预算上限的结果纠偏

目标用户需要符合原型用途的静态道具模型，生成接口成功不足以证明交付结果满足需求。项目采用单个 Agent，根据用户意图和技术检查反馈，在预算上限内决定接受结果、对现有模型减面、调整生成描述或支持的参数后重新生成，或停止并解释未满足的技术要求；整个过程保留用户的原始约束。

相比仅执行一次预设生成链路，这一选择将根据实际反馈作出下一步决策作为 Agent 的核心价值。代价是需要可信的验证证据、明确的预算与终止条件，并承担可能增加的生成成本和等待时间。默认技术上限已在 [CONTEXT](../../CONTEXT.md#默认技术上限) 中确定，生产次数见 ADR 0006，模型调用额度与执行时限见 [ADR 0013](0013-execution-limits-and-local-stop.md)。

根据 [ADR 0003](0003-technical-validation-only.md)，MVP 仅采用技术检查，排除视觉检查。因此，纠偏与自动接受结果均不构成对物体类别、风格或外观符合性的保证。

根据 [ADR 0004](0004-agent-decisions-and-deterministic-execution.md)，Agent 负责策略决策，程序负责确定性执行与检查。

根据 [ADR 0005](0005-decimation-and-regeneration-only.md)，MVP 自动纠偏仅开放减面和重新生成，每次操作后重新执行三类技术检查，并记录选择依据。

根据 [ADR 0006](0006-three-production-submissions-per-request.md)，每次请求最多提交一次首次生成和两次纠偏操作；额度耗尽阻止新提交，已提交操作仍继续查询与验收。
