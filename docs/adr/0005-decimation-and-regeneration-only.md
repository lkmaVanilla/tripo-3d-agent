# MVP 自动纠偏仅开放减面和重新生成

技术检查失败后，Agent 需要有明确且有限的可选操作。MVP 仅开放两类自动纠偏：对可处理的现有模型降低三角面数，以及保留用户约束、调整生成描述或 Tripo 支持的参数后重新生成候选模型。

Agent 根据实际失败项、工具适用条件和剩余预算选择动作，并记录选择依据。每次处理后重新执行文件有效性、几何规模和文件体积三类技术检查；没有可行操作时停止并解释原因，不得通过放宽原始约束来使结果通过检查。生产额度耗尽只阻止新增操作，已提交操作仍继续查询与验收。

这一选择将首版纠偏工具范围限制在两类生产操作，同时保留针对现有产物处理和重新生成之间的策略选择。减面和重新生成共用最多两次纠偏额度，见 [ADR 0006](0006-three-production-submissions-per-request.md)。Agent 可调整生成描述、目标面数和贴图质量；模型版本及其他参数由程序固定，产物与参数边界见 [ADR 0012](0012-glb-artifacts-and-controlled-parameters.md)。

Tripo 提供对现有模型的异步减面能力，见 [官方减面文档](https://developers.tripo3d.ai/en/docs/mesh-decimate)。接口完成后仍须检查实际产物，不能将目标面数参数当作已满足上限的证据。
