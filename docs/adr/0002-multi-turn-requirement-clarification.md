# 关键需求澄清最多三轮，明确后提前结束

自然语言资产请求中的关键缺失、歧义或冲突可能无法通过一次问答解决，但持续追问会延迟资产交付。项目允许 Agent 开展最多三轮关键需求澄清；Agent 判定关键需求已经明确，或澄清达到三轮时，即结束澄清并进入后续执行或生成。

澄清结束后，如果仍有信息缺失，Agent 明确展示采用的默认假设并继续生成；如果仍存在无法同时满足的硬约束，则解释冲突并结束任务，不调用生成接口。默认假设不得覆盖或放宽已有硬约束。

这一选择保留了多轮对话消除歧义的空间，同时为澄清阶段设置明确上限，并避免通过舍弃硬约束来强行生成。它要求后续设计支持等待用户回复、保留已澄清的内容、跟踪轮次，以及在未生成模型时给出可解释的任务结束结果。
