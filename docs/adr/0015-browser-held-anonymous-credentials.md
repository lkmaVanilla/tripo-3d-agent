# 浏览器持有匿名凭证，服务端校验会话归属

匿名访客需要无需登录即可创建多个会话，并在刷新或重新打开页面后找回自己的记录。服务端自动签发随机匿名访问凭证，以第一方持久 Cookie 保存在浏览器；服务端记录凭证校验信息、有效期及会话归属。

凭证仍有效时，同一浏览器可以找回此前创建的多个会话。会话列表、详情、对话、WebSocket 进度、模型下载和任务控制均按凭证校验归属；其他访客仅凭会话链接不能获得访问权。

首版不提供跨设备恢复，也不提供凭证丢失后的旧会话找回。更换浏览器、清除凭证或凭证过期后，不能仅凭会话 ID 重新授予访问权。该凭证识别匿名访问主体，不建立经过验证的真实个人账号。

这一选择保留免登录体验，并使一个匿名访客与多个会话的归属关系明确。代价是访问连续性依赖浏览器保留有效凭证；失去凭证不等于后台任务停止或数据已删除，后台执行仍遵循 [ADR 0013](0013-execution-limits-and-local-stop.md)。

首版匿名凭证连续 30 天未访问后失效，正常访问时滚动延长有效期。会话数据在结束后保留 7 天；即使凭证仍有效，也不能访问已到期删除的数据，见 [ADR 0018](0018-anonymous-session-retention-and-expiry.md)。

持久 Cookie 需设置有效期，浏览器可能清除 Cookie，应用不能承诺一定保留到期；服务端仍须检查凭证有效性。机制参考：[MDN Set-Cookie 文档](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。
