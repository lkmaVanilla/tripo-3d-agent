# 长期以 Tripo API 限定资产生产与加工能力

项目定位扩展为面向 3D 创作者的资产制作助手，资产类型和制作阶段将逐步增加。用户选择长期仅覆盖 Tripo 提供的资产制作操作，因此将 Tripo API 作为唯一的资产生产与加工能力来源；不接入其他 3D 生成服务，也不使用本地建模工具补齐其未开放的生产操作。

相比按任务需要接入多个 3D 工具的方案，这一选择集中维护一套供应商的输入、任务与结果协议；代价是产品可提供的制作操作、适用输入与能力演进受 Tripo API 限制。骨骼绑定、动画、图片及已有模型输入属于长期方向，具体范围需在对应阶段核对 Tripo 的开放接口并完成项目接入与验收，不能将供应商能力直接宣告为项目已有能力。

此边界仅约束资产生产与加工。Agent 的模型服务、应用调度、下载、技术检查和网页展示继续由各自组件承担，沿用 [ADR 0004](0004-agent-decisions-and-deterministic-execution.md) 的策略决策与确定性执行分工。当前静态资产 MVP 的验收要求保持适用，本次仅记录长期能力边界，不实现新制作能力。
