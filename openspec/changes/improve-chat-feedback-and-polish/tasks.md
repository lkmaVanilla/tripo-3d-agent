## 3. 连接生命周期与新鲜度

关联：[HTTP 命令和事件重连保持会话一致、临时活动反馈具有独立且可清理的生命周期](specs/chat-asset-workspace/spec.md)、[设计决策 3](design.md)。

- [x] 3.1 将连接生命周期以结构化浏览器内通知交给工作区状态，记录当前有效快照的接收时间；假连接测试验证 onopen 但无快照仍为同步中、相同游标快照可以续期、错误会话或落后快照不能恢复实时提示，HTTP／WS 公开协议不变。
- [x] 3.2 实现可注入时间的 15 秒快照新鲜度检测，失效时清除实时忙碌展示并复用既有只读刷新和重连流程；假时间测试验证静默连接、持续心跳、恢复后终态和重复触发只有一条恢复链，不新增制作或消息 POST。
- [x] 3.3 统一清理切换会话、返回首页、不可访问和关闭时的连接资源与计时器，恢复前台时检查快照是否过期；测试验证会话代次和 socket 身份双重隔离、同一会话旧 socket 迟到回调无效，过期会话不继续重连。
